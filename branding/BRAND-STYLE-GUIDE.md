# Seraphonix Studios - Brand Style Guide

## Brand Identity

### Name Origin
**Seraphonix** represents the fusion of:
- **Seraph**: Six-winged beings of pure light, attendants to the divine, perpetually in motion
- **Phoenix/Nix**: Technological innovation and digital rebirth

### Core Philosophy
> "Where imagination crystallizes into digital reality through neural networks and creative synthesis"

The most powerful creative forces are those that never stop moving, never stop burning, never stop ascending.

## Logo

### Primary Logo Mark
```
◉ SERAPHONIX
```

### Usage
- **On Dark**: White text with cyan accent on ◉
- **On Light**: Black text with cyan accent on ◉
- **Minimum Size**: Never smaller than 24px height for "◉" symbol
- **Clear Space**: Maintain space equal to ◉ height on all sides

### Variations
1. **Full Logo**: ◉ SERAPHONIX STUDIOS
2. **Icon Only**: ◉ (for favicons, avatars, app icons)
3. **Monochrome**: For single-color printing

## Typography

### Primary Font: Orbitron
- **Usage**: Headers, UI elements, navigation, branding text
- **Weights**: 400, 500, 700, 900
- **Style**: Geometric sans-serif, futuristic, tech-forward

**Example:**
```
SERAPHONIX - 900 weight
Navigation - 700 weight
Body UI - 400 weight
```

### Secondary Font: Rajdhani
- **Usage**: Body text, descriptions, data display
- **Weights**: 300, 400, 500, 600, 700
- **Style**: Clean, readable, technical

**Example:**
```
Body text at 16px, weight 400
Descriptions at 14px, weight 300
Data/Stats at 18px, weight 600
```

### Type Scale

| Size | Usage | Font |
|------|-------|------|
| 48px | Hero titles | Orbitron 900 |
| 32px | Section headers | Orbitron 700 |
| 24px | Subheaders | Orbitron 500 |
| 18px | UI labels | Orbitron 500 |
| 16px | Body text | Rajdhani 400 |
| 14px | Captions | Rajdhani 300 |
| 12px | Labels, tags | Orbitron 400 |

## Voice & Tone

### Visionary
Speak of possibilities, not limitations. Every message carries future potential.
- ✅ "Scale infinitely—from prototype to planet"
- ❌ "Our system handles up to 1000 users"

Dynamic, electric, alive. Use active verbs. Move forward.

Honor the magic in technology. Words evoke wonder while delivering precision.

Engineering-backed claims. Every promise kept.

## Visual Elements

### The Neural Sphere
- 3D wireframe icosahedron as primary interface
- Central cyan core with 6 satellite nodes
- Rotating seraph wings (6 beams of light)
- Many-eyed orbiting lights (12 points)
- Rays of creation emanating outward

### Glow Effects
All primary elements use glow:
- `box-shadow: 0 0 20px rgba(0, 212, 255, 0.5)`
- Text glow for emphasis
- Pulsing animations on key elements

### Spacing System
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- 2xl: 48px

### Border Radius
- Small: 6px (buttons, inputs)
- Medium: 12px (cards, panels)
- Large: 16px (windows, modals)
- Full: 100px (pills, tags)

## Usage Guidelines

### Do:
- Use sentence case for headings (not Title Case)
- Keep clear space around logo
- Use approved color combinations
- Maintain high contrast for accessibility
- Animate with purpose (never gratuitously)

### Don't:
- Stretch or distort logo
- Use unapproved color combinations
- Place logo on busy backgrounds without contrast
- Use more than 2 font families
- Overuse glow effects (diminishes impact)
